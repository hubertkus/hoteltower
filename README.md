# hoteltower
rezerwacja pokoju w hotelu Tower

## Opis projektu

hoteltower to aplikacja ASP.NET Core Web API
umożliwiająca rejestrację użytkowników i rezerwację pokoju w Hotelu Tower

## Technologie

- C#
- ASP.NET Core Web API
- Entity Framework Core
- MsSql
- MediatR
- FluentValidation
- CQRS
- Grpc

## Wymagania

Do uruchomienia projektu potrzebujesz:

- .NET SDK
- MsSql

## Uruchomienie

1. Sklonuj repozytorium.
2. Skonfiguruj połączenie z bazą danych.
3. Otwórz terminal w katalogu projektu.
4. Uruchom aplikację:

   dotnet run

## Testy

Aby uruchomić testy, wykonaj:

dotnet test

## Dokumentacja API

Dokumentacja API może być dostępna przez Swagger/OpenAPI
